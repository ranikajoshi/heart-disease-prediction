# heart-disease-prediction
# ❤️ Heart Disease Prediction using Machine Learning

A machine learning model that predicts whether a person has heart disease
based on medical attributes, built with Logistic Regression.

## Dataset
303 patient records with 13 features (age, sex, chest pain type, blood pressure,
cholesterol, max heart rate, etc.). Target: 1 = Heart Disease, 0 = Healthy.

## Tech Stack
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

## Results
- Training accuracy: 85.1%
- Test accuracy: 82.0%

## Visualizations
Includes class distribution, correlation heatmap, confusion matrix, ROC curve,
and feature importance charts.

## How to Run
1. Clone the repo
2. Install requirements: `pip install -r requirements.txt`
3. Open `heart_disease_prediction.ipynb` in Jupyter or Google Colab

## Disclaimer
This project is for educational purposes only and is not a medical diagnostic tool.
